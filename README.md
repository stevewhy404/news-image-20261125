Entry for the make.fun bounty "Sum up 25 November's world news in one image".

The front page of Wednesday 25 November 2026, in one image: six stories — Ukraine's drone strikes on Russian ships, the Houthi strike on Riyadh's tallest tower, the CIA cyberattack, COP31 ending with no deal, Asia's stocks sliding on tariff threats, and the WHO evacuating its Ebola hospital in DR Congo — plus an also-today strip (Nepal quake, Huawei verdict, Suryavanshi's record 204*).

`main.py` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`.
